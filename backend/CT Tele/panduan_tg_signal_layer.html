Panduan TG Signal Layer

Sistem yang membaca sinyal zona dari grup Telegram, lalu mengeksekusinya otomatis di MetaTrader 4 dengan SL, kunci profit, dan trailing. Panduan ini mencakup instalasi, setting EA, hasil backtest, dan cara mengambil riwayat sinyal.

Cara kerja sistem

Sistem ini punya dua bagian yang berjalan di VPS yang sama: pembaca sinyal (script Python) dan EA di MT4. Keduanya berkomunikasi lewat satu file teks.

1 · TELEGRAMGrup sinyalAdmin mengirim SELL 62-66 atau BUY 47-43.
2 · PYTHONPembaca sinyalMembaca pesan baru, mengabaikan rekap dan obrolan, cek cadangan tiap 15 detik.
3 · FILEtg_signals.txtDi folder Common\Files, dipakai bersama semua MT4 di VPS.
4 · MT4EA TG Signal LayerMelengkapi harga zona, memasang order, mengelola SL dan trailing.

Yang dilakukan EA saat sinyal zona masuk

  • Melengkapi harga. Sinyal hanya menulis dua digit terakhir. SELL 62-66 saat harga 4060 menjadi zona 4062–4066. Titik pertama (4062) disebut ZERO, titik terakhir (4066) disebut LAST.
  • Harga belum sampai ZERO: EA memasang pending (sell limit / buy limit) di ZERO.
  • Harga sudah melewati ZERO tapi masih di zona: EA langsung entry market. Dari backtest, entry seperti ini justru menyumbang profit.
  • Harga sudah menembus LAST lebih dari 5 pips: sinyal diabaikan.
  • Pesan "Buy Now / Sell Now": diabaikan. Pesan ini selalu disusul sinyal zona sekitar 24 detik kemudian.
  • Pending yang tidak tersentuh 60 menit dihapus. Maksimal 3 sinyal aktif bersamaan. Posisi berlawanan boleh berjalan bersamaan, masing-masing dengan SL dan TP sendiri.

Instalasi di VPS

Semua langkah dikerjakan di VPS Windows yang menjalankan MT4 Exness. Langkah 1 dan 2 khusus untuk Windows Server 2012 R2; di Windows 10/11 cukup install Python versi terbaru.

1

Pasang Universal C Runtime

Tanpa komponen ini, installer Python gagal dengan error 0x80070643.

  1. Buka catalog.update.microsoft.com, cari KB3118401.
  2. Download baris Update for Windows Server 2012 R2 (KB3118401), sekitar 992 KB.
  3. Jalankan file .msu, lalu restart VPS.
2

Install Python 3.11.9

Python 3.12 ke atas tidak mendukung Server 2012 R2. Download Windows installer (64-bit) dari python.org/downloads/release/python-3119/.

  1. Klik kanan installer → Run as administrator.
  2. Centang Add python.exe to PATH, lalu Install Now.
  3. Buka Command Prompt baru, jalankan:
pip install telethon
3

Ambil API Telegram

Login di my.telegram.org → API development tools. Isi App title dan Short name (huruf dan angka, 5–32 karakter), Platform pilih Desktop. Catat api_id (angka) dan api_hash (huruf-angka panjang).

Jangan bagikan api_hash dan file tg_signal.session ke siapa pun. Keduanya sama dengan akses ke akun Telegram.

4

Siapkan script

Buat folder C:\tgbridge, taruh tg_signal_reader.py di sana, lalu edit dengan Notepad. API_HASH wajib pakai tanda kutip, API_ID tidak.

API_ID = 12345678
API_HASH = "isi_api_hash_anda"
CHAT_ID = -100xxxxxxxxxx
5

Login dan cari ID grup

cd C:\tgbridge
python tg_signal_reader.py --list
  • Masukkan nomor HP format internasional tanpa spasi, misalnya +6281234567890.
  • Kode login masuk sebagai chat dari akun "Telegram" di aplikasi, bukan SMS.
  • Salin ID grup sinyal (berawalan -100) ke CHAT_ID, lalu simpan.

Dua peringatan Failed to load SSL library dan cryptg module not installed boleh diabaikan.

6

Buat run_reader.bat dan jalankan

Browser sering memblokir download .bat, jadi buat sendiri di Notepad, lalu Save As ke C:\tgbridge dengan Save as type: All Files dan nama run_reader.bat.

@echo off
title TG Signal Reader
cd /d %~dp0
:loop
python tg_signal_reader.py
echo.
echo Pembaca sinyal berhenti. Restart otomatis dalam 10 detik...
timeout /t 10 /nobreak >nul
goto loop

Klik dua kali run_reader.bat. Tanda pembaca bekerja:

  • Memantau grup: … saat start, menandakan CHAT_ID benar.
  • SINYAL | … untuk sinyal, abaikan | … untuk rekap dan obrolan. SINYAL (p) berarti tertangkap lewat cek cadangan.
  • masih aktif | … setiap 30 menit.

Auto-start setelah VPS restart: tekan Win + R, ketik shell:startup, lalu taruh shortcut run_reader.bat di folder itu. Tanpa ini, pembaca sinyal mati diam-diam setiap VPS restart.

7

Pasang EA di MT4

  1. MT4 → File → Open Data Folder → MQL4 → Experts, salin file EA.
  2. F4 (MetaEditor), buka file, F7 (Compile). Harus 0 error.
  3. Buka chart XAUUSD baru. Satu chart hanya bisa menjalankan satu EA, jadi jangan pakai chart EA lain.
  4. Seret EA ke chart, centang Allow live trading, isi tab Inputs (lihat Setting EA).
  5. Tombol AutoTrading hijau, dan tab Experts menampilkan TG Signal Layer aktif di XAUUSD.

Dua akun demo, satu pembaca. Pakai dua instalasi MT4 terpisah (satu MT4 hanya bisa login satu akun). Keduanya membaca file sinyal yang sama, jadi cukup satu jendela pembaca sinyal.

Jangan pasang EA ini di MT4 akun lain, karena akun itu juga akan ikut mengeksekusi semua sinyal.

Cara kerja mode tunggu (kandidat 2 dan 3)

  • EA tidak memasang pending, tetapi menunggu di memori. Tab Experts mencatat menunggu harga masuk zona.
  • Kandidat 2: setiap candle M5 close, EA mengecek rejection candle: ekor menyentuh ZERO lalu close kembali keluar zona, ekor ≥ 2× body dan ≥ 50% panjang candle, ekor sisi lain ≤ 25%, panjang candle minimal 10 pips. Kalau ada, entry market dengan SL di ujung ekor + 3 pips (dibatasi 10–40 pips). Kalau candle M5 close menembus LAST lebih dari 5 pips sebelum rejection, sinyal batal.
  • Kandidat 3: setelah harga menyentuh ZERO, selama harga masih di zona EA mengecek EMA 50 M15 (candle M15 terakhir yang sudah close). SELL hanya kalau close di bawah EMA, BUY hanya kalau di atas. Kalau searah, entry market.
  • Tidak ada entry dalam 60 menit, sinyal batal. Sinyal yang sedang ditunggu hilang kalau MT4 di-restart.

Dashboard di chart (v1.31)

Panel di pojok kiri atas chart, diperbarui tiap detik, jam dalam WITA. Matikan dengan ShowDashboard = false.

  • Mode, lot, TP, status AutoTrading, spread, dan sinyal terakhir. Baris sinyal berubah oranye kalau lebih dari 2 jam tanpa sinyal baru, tanda pembaca mungkin mati.
  • Balance, equity, floating, hasil hari ini (TP / kunci profit / SL), total, dan max drawdown sejak EA aktif.
  • Daftar posisi, pending, dan sinyal yang sedang ditunggu, plus 6 kejadian terakhir.

Hasil backtest

Periode 12 Oktober – 10 November 2026 (22 hari trading), 719 sinyal zona, data harga M1 XAUUSD, spread 0,8 pips, lot 0,01.

Setiap hasil ditulis sebagai dua angka. Terburuk menganggap SL selalu kena lebih dulu di dalam candle M1. MT4 memakai jalur harga di dalam candle seperti Strategy Tester MT4. Hasil nyata kemungkinan di antara keduanya.

Catatan tentang rekap grup

Grup mencatat sekitar 93% TP. Dengan aturan nyata, winrate tertinggi yang bisa didapat sekitar 72–75% (TP 10). Rekap grup menghitung sinyal sebagai TP kalau salah satu dari tiga titik entry kena TP, dengan TP bebas 10/20/30, dan mencatat SL hanya kalau titik LAST kena SL.

Ambil riwayat sinyal untuk backtest

Mengekspor sinyal dari grup Telegram lengkap dengan jam kirimnya ke file signals_history.csv. Bisa dikerjakan di VPS atau di laptop biasa; login Telegram sama saja dari komputer mana pun.

1

Siapkan pembaca sinyal

Ikuti langkah 1–5 di tab Instalasi. Di laptop Windows 10/11 langkah 1 tidak perlu, dan Python versi terbaru boleh dipakai.

2

Ekspor riwayat

cd C:\tgbridge
python tg_signal_reader.py --history 30
  • 30 artinya 30 hari ke belakang. Bisa diganti 60 atau 90 untuk menguji periode lain.
  • Hasilnya signals_history.csv di folder yang sama. Rekap harian, pesan "TP yaa", dan obrolan tidak ikut.
3

Ambil data harga M1 (kalau periodenya baru)

History Center (F2) sering berisi data lama. Pakai script ExportM1.mq4, yang membaca data langsung dari chart:

  1. Taruh ExportM1.mq4 di MQL4 → Scripts, compile dengan F7.
  2. Buka chart XAUUSD M1, tekan Home beberapa kali sampai periode yang dibutuhkan termuat.
  3. Navigator → Scripts → seret ExportM1 ke chart, isi jumlah hari.
  4. File XAUUSD_M1.csv muncul di Common\Files (File → Open Data Folder, naik satu folder, lalu Common → Files).
4

Kirim untuk dianalisis

Kirim signals_history.csv dan, kalau ada, XAUUSD_M1.csv. Jangan kirim file tg_signal.session atau api_hash.
